# Weather Trend Forecasting

## Project Overview
This project analyzes global weather data and forecasts future weather trends using time-series forecasting and machine learning techniques.

The project includes:
- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- Anomaly Detection
- ARIMA Forecasting
- Feature Importance Analysis
- Spatial Weather Analysis

---

## Dataset
Dataset used:

World Weather Repository Dataset from Kaggle

Dataset Link:
https://www.kaggle.com/datasets/nelgiriyewithana/global-weather-repository

## Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/weather-trend-forecasting.git
```

Move into the project directory:

```bash
cd weather-trend-forecasting
```

Create virtual environment (optional):

```bash
python -m venv venv
```

Activate virtual environment:

### Windows
```bash
venv\Scripts\activate
```

### Linux/Mac
```bash
source venv/bin/activate
```

Install required libraries:

```bash
pip install -r requirements.txt
```

---

## How to Run

Start Jupyter Notebook:

```bash
jupyter notebook
```

Open:

```bash
weather_analysis.ipynb
```

Run all cells in sequence.

## Forecasting Model

### ARIMA
Used ARIMA model for weather trend forecasting using the last_updated feature.

Evaluation Metrics:
- MAE
- RMSE
- R² Score
